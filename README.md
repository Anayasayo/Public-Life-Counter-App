# 3DPG Life Counter

Free Magic: The Gathering life counter by [3D Printed Games](https://3dprintedgames.store). It works offline, with no account or ads.

**Get it here: [3dprintedgames.store/pages/free-downloads](https://3dprintedgames.store/pages/free-downloads)**

- **Android / Fire tablets:** [download the app](https://apps.3dprintedgames.store/downloads/3DPG-Life-Counter.apk)
- **iPhone / iPad:** [use the browser version](https://apps.3dprintedgames.store/life-counter/) (Safari → Share → Add to Home Screen), or [install the full app with SideStore](https://3dprintedgames.store/pages/install-life-counter-iphone)

This repo only hosts the finished app. The website at apps.3dprintedgames.store is published to the `gh-pages` branch, and past versions are on the [Releases](https://github.com/Anayasayo/Public-Life-Counter-App/releases) page.
