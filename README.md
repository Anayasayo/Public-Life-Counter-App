# 3DPG Life Counter

Free Magic: The Gathering life counter by [3D Printed Games](https://3dprintedgames.store). It works offline, with no account or ads.

**[Install instructions](https://anayasayo.github.io/Public-Life-Counter-App/)** (iPhone, iPad, Android and Fire tablets)

- **iPhone / iPad:** install it with [SideStore](https://docs.sidestore.io). In SideStore, go to Sources → + and add:
  `https://github.com/Anayasayo/Public-Life-Counter-App/releases/latest/download/source.json`
- **Android / Fire:** download [3DPG-Life-Counter.apk](https://github.com/Anayasayo/Public-Life-Counter-App/releases/latest/download/3DPG-Life-Counter.apk) and open it.

Every version is on the [Releases](https://github.com/Anayasayo/Public-Life-Counter-App/releases) page.
